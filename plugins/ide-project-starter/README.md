# IDE Project Starter plugin

Version-Timestamp: 2026-09-10 13:12:49 AST
Version: 0.6.0

Invoke project-starter from an authorized client or project folder. Follow core/docs/CLIENT-ONBOARDING.md. This package contains no client memory or project identities. Helpers require local Python; initialization additionally requires the pinned Copier environment. No hooks, MCP servers, remote services or global setup are included.
