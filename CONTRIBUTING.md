# Contributing

Version-Timestamp: 2026-09-10 18:27:14 AST

Report problems or ideas through this repository's issues. Include a sanitized or fictional reproduction and the release version. Do not submit client records, personal project memory, credentials or private debug logs.

This repository is a generated distribution. The maintainer reviews feedback and proposed changes in the private source repository, runs relevant checks, then generates a new public release. Public pull requests can describe a proposal; they are not merged directly into an independently maintained implementation.

A useful report says what you expected, what happened, how to reproduce it and which existing files must remain untouched. Improvements to an existing skill are preferred over duplicate skills when they solve the same problem.
